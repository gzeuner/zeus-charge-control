SonnenBatterie Access-Token finden und sicher für Zeus Charge Control einrichten

So findest du die lokale Batterieoberfläche, aktivierst die JSON API v2 und übernimmst den Token in die aktuelle Konfiguration von Zeus Charge Control.

Ein Access-Token ist ein geheimer Zugangsschlüssel für API-Anfragen. Wenn du Zeus Charge Control mit deiner Batterie verbinden möchtest, brauchst du neben der erreichbaren Batterieadresse auch den passenden Token. Die Oberfläche und die verfügbaren API-Funktionen unterscheiden sich je nach Batteriemodell und Softwarestand. Die folgende Anleitung beschreibt den Zugriff über die lokale Weboberfläche und die JSON API v2. Wenn Menüs oder Anmeldeschritte bei deiner Anlage anders aussehen, orientiere dich an der Dokumentation im Batterie-Dashboard oder an den Unterlagen für dein Modell.

Token wie ein Passwort behandeln

Teile den Token nicht in Chats, Screenshots, öffentlichen Repositories oder ungeschützten Logs. Er kann den Zugriff auf Batterieinformationen und – bei aktivierter Schreibfunktion – Steueraktionen ermöglichen. Nutze ihn nur für Anwendungen und Systeme, denen du vertraust.

Das Wichtigste in einer Minute

  • Finde die lokale IP-Adresse deiner Batterie in der Geräteliste des Routers.
  • Öffne die Batterieoberfläche aus demselben Heimnetz und melde dich mit den für dein Modell gültigen Zugangsdaten an.
  • Aktiviere unter Software-Integration → JSON API die benötigten API-Rechte und kopiere den angezeigten Token.
  • Hinterlege Batterieadresse und Token in der externen Zeus-Konfiguration oder über die vorgesehenen Umgebungsvariablen – nicht in einem öffentlichen Startskript.

Was du brauchst

  • Eine sonnenBatterie mit erreichbarer lokaler Schnittstelle.
  • Zugriff auf das Heimnetz und die Router-Geräteliste.
  • Die für deine Anlage gültigen Zugangsdaten; bei einer Erstanmeldung kann das Initialpasswort auf dem Typenschild stehen.
  • Ein Gerät im selben Netzwerk, zum Beispiel einen Computer oder ein Smartphone.

Die Namen und Menüs können sich zwischen Batteriegenerationen und Firmwareständen unterscheiden. Sonnen weist in den Versionshinweisen außerdem auf aktualisierte Dokumentation zur Local REST API im Dashboard hin. Die dort angezeigten Hinweise für dein konkretes System haben Vorrang.

1. Lokale IP-Adresse der Batterie finden

  1. Router öffnen: Melde dich an der Benutzeroberfläche deines Routers an.
  2. Geräteliste ansehen: Suche in der Liste der verbundenen Geräte nach einem Eintrag, der beispielsweise mit SB- beginnt. Die angezeigte Bezeichnung kann abweichen.
  3. Adresse notieren: Übernimm die lokale IP-Adresse, zum Beispiel 192.168.178.42. Das ist nur ein Beispiel; verwende die Adresse aus deinem Netzwerk.

Falls du die Batterie nicht erkennst, prüfe in der Router-Geräteliste auch kabelgebundene Geräte oder verbundene Netzwerkkomponenten. Die Batterie und dein Browsergerät müssen sich gegenseitig im Heimnetz erreichen können.

2. Lokale Oberfläche öffnen und anmelden

  1. Verbinde Computer oder Smartphone mit demselben Heimnetz wie die Batterie.
  2. Gib die IP-Adresse in die Adresszeile des Browsers ein, zum Beispiel http://192.168.178.42.
  3. Wenn die lokale Anmeldeseite eine Rollenwahl anbietet, wähle die zu deinem Zugang passende Rolle. In manchen Anleitungen oder Systemen wird hierfür User angezeigt.
  4. Bei der ersten Anmeldung kann das Initialpasswort vom Typenschild der Batterie verlangt werden. Wenn dein System bereits eingerichtet ist, verwende stattdessen das von dir gesetzte Passwort.

Die Anmeldemaske ist nicht bei jeder Batteriegeneration identisch. Wird kein lokaler Login angeboten oder akzeptiert das Gerät die beschriebenen Zugangsdaten nicht, verwende die aktuelle Modell-Dokumentation oder wende dich an den Installationsbetrieb beziehungsweise den Sonnen-Support.

3. JSON API v2 aktivieren und Token kopieren

  1. Öffne in der Batterieoberfläche den Menüpunkt Software-Integration.
  2. Wechsle zum Bereich oder Reiter JSON API.
  3. Aktiviere Read API, wenn die Anwendung Batteriedaten lesen soll.
  4. Aktiviere Write API nur, wenn du die Steuerfunktionen einer Anwendung wie Zeus Charge Control nutzen möchtest und die Funktion für dein System verfügbar ist.
  5. Kopiere den angezeigten Auth.-Token und bewahre ihn geschützt auf.

Die Write API ist nicht überall verfügbar

Die Freigabe hängt vom System und den aktiven Diensten ab. Sonnen weist in seinen Versionshinweisen darauf hin, dass externe Steuerung über die Write API für bestimmte Kunden mit sonnenVPP, Preisoptimierung oder Direktvermarktung nicht verfügbar ist. Umgehe solche Einschränkungen nicht. Prüfe die Hinweise im Dashboard oder kläre die Freigabe mit Sonnen beziehungsweise deinem Installationsbetrieb.

Im September 2026 hat sonnen für Software-Version 1.40 zusätzliche Funktionen der Local REST API und eine aktualisierte Dokumentation im Dashboard angekündigt. Details findest du in den offiziellen Versionshinweisen von sonnen.

4. Access-Token in Zeus Charge Control hinterlegen

Die aktuelle Version von Zeus Charge Control erwartet den Token in der Anwendungskonfiguration. Du musst ihn nicht in ein Startskript hineinschreiben. Für das ZIP-Paket kopierst du zunächst die Beispielkonfiguration und passt die externe Datei an:

Copy-Item config/application.properties.example config/application.properties

Die relevanten Eigenschaften sehen so aus:

battery.url=${BATTERY_URL:}
battery.authToken=${BATTERY_AUTH_TOKEN:}

Du kannst die Werte über die Umgebungsvariablen BATTERY_URL und BATTERY_AUTH_TOKEN bereitstellen oder sie in deiner privaten config/application.properties setzen. Als Batterieadresse verwendest du die lokale URL deiner Anlage, zum Beispiel http://192.168.178.42. Der Token gehört in eine lokal geschützte Konfiguration und nicht in eine Datei, die du veröffentlichst oder mit anderen teilst.

Danach startest du das Paket wie in der Anleitung beschrieben. Öffne das Dashboard von Zeus Charge Control und prüfe, ob der Speicher erreichbar ist und plausible Werte angezeigt werden. Einen vollständigen Überblick über Version 4.0, Installation und Dashboard findest du im Artikel Zeus Charge Control: PV-Batterie intelligent mit dynamischen Strompreisen laden.

Für den Betrieb von Zeus Charge Control

Du benötigst Java 21 oder neuer. Das ZIP-Paket bringt Startskripte für Windows und Linux/macOS sowie eine Konfigurationsvorlage mit. Die Anwendung wird standardmäßig lokal bereitgestellt; ändere die Netzwerkanbindung nur bewusst und schütze den Zugriff auf dein Heimnetz.

Wenn es nicht funktioniert

  • Batterieoberfläche nicht erreichbar: Prüfe IP-Adresse, WLAN beziehungsweise Ethernet und ob beide Geräte im selben Netzwerk sind.
  • Anmeldung schlägt fehl: Rollenwahl und Passwort können je nach Modell abweichen. Prüfe die Geräteunterlagen und nutze das Initialpasswort nur, wenn die Anlage noch eine Erstanmeldung erwartet.
  • Token wird abgelehnt: Kopiere ihn erneut und kontrolliere, dass keine Leerzeichen oder Zeilenumbrüche mitkopiert wurden. Prüfe außerdem, ob du den Token für die richtige lokale Batterie verwendest.
  • Lesen klappt, Steuern nicht: Prüfe, ob die Write API aktiviert und für deine Anlage freigegeben ist. Manche Energiemanagement- oder Vermarktungsdienste schränken sie ein.
  • Zeus zeigt keinen Speicher: Kontrolliere battery.url, battery.authToken und die Erreichbarkeit des Geräts vom Rechner, auf dem Zeus läuft. Sieh anschließend in die Anwendungslogs.

Häufige Fragen

Ist der Access-Token dasselbe wie mein Sonnen-Portal-Passwort?

Nein. Das Portal- beziehungsweise Gerätepasswort dient der Anmeldung. Der API-Token wird für autorisierte Anfragen an die lokale Schnittstelle verwendet.

Muss ich Read API und Write API beide aktivieren?

Zum Auslesen von Daten ist Read API erforderlich. Für Steuerfunktionen wird zusätzlich Write API benötigt, sofern sie von deinem System unterstützt und freigegeben wird. Aktiviere nur die Rechte, die du tatsächlich brauchst.

Kann ich den Token von unterwegs über das Internet abrufen?

Diese Anleitung setzt den Zugriff auf die lokale Oberfläche im Heimnetz voraus. Richte keine ungeschützte Portweiterleitung zur Batterie ein. Für Fernzugriff nutze nur ein sicher konfiguriertes Netzwerkverfahren, das du selbst verantwortest.

Was mache ich, wenn meine Menüs anders aussehen?

Die Oberfläche hängt von Modell und Softwarestand ab. Prüfe die Dokumentation im Dashboard und die offiziellen sonnen-Versionshinweise. Bei Unklarheiten hilft der Installationsbetrieb oder der Hersteller-Support.

Fazit

Mit der lokalen IP-Adresse, einem passenden API-Zugang und einem sicher verwahrten Token lässt sich Zeus Charge Control mit einer kompatiblen sonnenBatterie verbinden. Die konkreten Menüs und verfügbaren Rechte können sich je nach Anlage unterscheiden; besonders die Write API ist nicht in jeder Konfiguration verfügbar.
